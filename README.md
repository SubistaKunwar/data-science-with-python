## About This Assignment

This is my Pandas assignment where I worked with a CSV dataset containing order and customer information.

I used Python and Pandas to clean the data, check missing values, remove duplicate records, filter the data, and create some new columns.

## What I Did

- Read the CSV file using Pandas
- Cleaned the column names
- Removed empty rows
- Checked missing values
- Removed rows where sales was missing
- Filled missing profit using the mean
- Filled missing discount using the median
- Replaced missing customer names with "Unknown"
- Checked and removed duplicate Order IDs
- Filtered orders based on unit price and status
- Created a `total_amount` column
- Created a `customer_type` column
- Displayed the final cleaned dataset
